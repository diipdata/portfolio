# Foto de Perfil

Para adicionar sua foto na seção **Sobre Mim**:
1. Coloque sua foto aqui nesta pasta: \ssets/images/profile/\
2. Nomeie o arquivo como:
   - \perfil.jpg\ (ou \perfil.png\ / \profile.jpg\)
3. A imagem será carregada automaticamente no site com borda iluminada e efeito glassmorphism!

Caso nenhuma foto seja adicionada, o site exibe automaticamente um avatar estilizado com seu monograma.
